# Solution Architect — Assets

This directory contains scripts, templates, and reference data
for the `solution_architect` skill.

## Directory Structure

```
solution_architect/
├── README.md           ← This file
├── templates/
│   └── install_script_template.sh   ← Standard script template
└── generated/          ← Scripts created by COA (auto-created)
```

## Usage

- **Templates** are read-only reference files used when generating new scripts.
- **Generated** scripts are stored here after creation for future reference and reuse.

Files here are deployed to sub-agents alongside the skill `.md` file.
