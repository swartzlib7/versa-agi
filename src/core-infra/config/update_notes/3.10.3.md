# 3.10.3 — Sudo access is seen on servers where it was reported as missing

## Tell the Primary User

- A fault is fixed. On a server that keeps its sudo settings folder readable by root only, the Chief Orchestrator Agent was told that sudo access had not been granted although the Primary User had switched it on, and its sudo commands were refused. The grant had been written correctly; the system looked for it in a folder it is not allowed to read. From this update it asks the operating system directly.
- If they switched on **Grant sudo Access** for this machine and you reported that it did not work: check your spawn prompt now. If it says AUTONOMOUS MODE, tell them once that it works and that nothing has to be set again. If it still says the grant did not land, tell them that, with the exact line.
