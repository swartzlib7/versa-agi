# 3.10.6 — Agents start again after the 3.10.5 update

## Tell the Primary User

- On most installs, every agent cycle failed straight after the update to 3.10.5, and after five failures the agent was paused with a circuit breaker notice. This update repairs it.
- The cause: 3.10.5 moved the prompt and environment files of a cycle into the agent's data folder, and on a normal install the files were given a group that no agent account is in, so the agent could not read them. They now carry the group every agent account is in.
- Nothing was lost. Messages and tasks that arrived while an agent was paused are still waiting for it.
- If an agent other than you is still paused, they can start it again from the dashboard (agitop), or you can with `agictl agent activate <name>`.
