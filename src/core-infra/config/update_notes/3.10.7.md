# 3.10.7 — Web search that reaches every install, a browser that stays signed in, and the GitHub CLI

## Maintenance after this update

Until this release an update did not refresh the search service: an install made before 3.8.0 kept the search settings it was installed with. This update refreshes it. Nothing below is known to be true on this instance. Make the check once and do what its result calls for.

1. **Web search after the refresh.** This note went to you only.
   - Check: `agictl search status`. Does at least one engine return results for the test search?
   - If none does: public search pages are refusing this machine. Tell the Primary User that a Brave Search or Exa key is the dependable route, and that they can set one in agitop under API Keys or give it to you (`agictl search set-key`).
   - If one or more do: there is nothing to do.

## Tell the Primary User

- An update now refreshes web search: the engine list, the search image and the optional Brave and Exa keys. Before, those changes reached only a new install.
- The same search asked again within ten minutes is answered from the earlier answer and not sent again, so repeats do not get the machine blocked. The time is `cache_minutes` under `[search]` in the settings; `agictl search web "<query>" --fresh` asks again.
- The browser can stay signed in to a website. Any browser command takes `--session <name>`; the sign-in is kept in the agent's own home and no other agent can use it. `agictl browser run` does several steps on one page, which is how a form is filled and sent (skill `browser_automation.md`).
- The earlier way of sending a form, `browser fill` and then `browser click` as two commands, never worked: the second command opened the page again with the field empty. Use `browser run`.
- The GitHub CLI (`gh`) is now installed with Versa AGi. With a token they make in their GitHub account, limited to the repositories and actions they choose, an agent can work with issues, pull requests, build results and releases (skill `github_cli.md`). Nothing is connected until they ask.
- The result of the check above: whether web search returned results after the refresh.
