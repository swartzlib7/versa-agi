# 3.10.1 — Lower cost per wake: your history setting, summaries, photos

## Tell the Primary User

- Resume Max Messages now takes effect. It is the number of recent messages an agent starts a cycle with (`sudo agitop` → the agent → Technical Setup; 50 for a new agent, 0 lets the model's size decide). Since September it was not used, and an agent on a large model started with up to 200 messages. From this update each agent starts with its own stored number. A smaller number costs less on every wake. They can change it per agent.
- Older conversation is no longer dropped. When a cycle starts with more messages than that number, the older part is first written up as a summary frame, and the agent starts with its newest summaries followed by the recent messages. Older summaries stay searchable.
- The summaries are written by the Compaction Model (`sudo agitop` → System Settings → General). When it is blank, each agent's own model writes them. A small model there keeps them cheap; they may want to choose one.
- They can now ask you whether Live Chat is on and have you change it: the listening time (off, 5, 10, 15 or 30 minutes) and Live Link (on or off). Before, only they could, in agitop. How: `agictl system live-chat`, `agictl system live-chat set <off|5|10|15|30>`, `agictl system live-chat link <on|off>`. Tell them what it was and what it is now.
- A photo an agent looks at now stays in its conversation until the cycle ends. With a Claude model, each photo after the first in a row used to make the provider bill most of the conversation again at the full price. That is fixed.
- Each agent's file of saved conversation steps is now trimmed to the newest 50 steps of each thread, as it was meant to be. It was never trimmed and could grow to several gigabytes. The first cycle of each agent after this update can take a few minutes longer to end while its file is cleaned, once, and the disk space is freed.
