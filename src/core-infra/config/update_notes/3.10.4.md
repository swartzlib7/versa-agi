# 3.10.4 — The backup an update makes: complete, one copy, out of the way

## Tell the Primary User

- Every update makes a backup first. From this update it holds everything: the databases, the settings and every agent's folder, as well as the code. Before, it held only the code and your own folder.
- It is kept in `/var/backups/versa-agi/`, which only root can read. It is no longer in an agent account's folder, and the full backup (`versa-agi-backup`) no longer picks it up. Backups that earlier versions left in the old place are removed once the new one exists.
- One backup is kept: each update replaces the previous one, after the new one is complete.
- Caches, downloaded models and installed dependencies are left out of it, since they are put back by their own tools. Git history is now included.
- The disk is checked first. If there is not enough room, the update goes ahead without a new backup, the earlier backup stays, and they get a message that says how much room was needed.
