# 3.10.0 — Live Link: messages reach you at once

## Tell the Primary User

- There is a new option, Live Link. It is off unless they turned it on during this update. To turn it on: `sudo agitop` → System Settings → Live Chat → Live Link, or answer the question at the next update.
- With Live Link on, messages reach agents without waiting for the next fetch. This machine keeps one outbound request open to the VersaVoice AI API and is told the moment an agent has a new message. A resting agent starts waking at once instead of at the next minute, and an agent in a chat reads a new message at once instead of within 10 seconds. The agent still needs its usual time to wake and to answer.
- The machine still accepts no connection from outside. If the link is down, messages arrive by the regular fetch, as before, and nothing is lost.
- Up to 20 of their agents can stay in a chat at the same time while Live Link is up. Without it the limit stays 5.
- agitop shows the link on the LINK line under System: up, down with the reason, or off.
- A network outage no longer fails cycles: while this machine cannot reach VersaVoice AI, agents on cloud models wait and start again when it is back.
- Shutting down or restarting this computer no longer cuts an agent off. An agent that is working or in a chat is told, gets up to 2 minutes to hand off and close its cycle, and carries on at its next start. A shutdown can take that much longer while an agent is busy. The time is `shutdown_grace_seconds` under `[agent]` in `/etc/versa-agi/setup.ini` (30 to 300 seconds; 0 turns it off).
- This computer no longer goes to sleep while an agent is working. The sleep waits until the agent's cycle has ended, and for a chat until it has been quiet for the listening time. On a laptop a shut lid still puts it to sleep, unless they answered yes to the lid question during this update. To change that answer they run the update again. `sleep_hold=false` under `[agent]` in `/etc/versa-agi/setup.ini` turns the whole thing off.
- After a power cut, or any cycle that did not close itself, the agent is told on its next wake that its last cycle was interrupted, and checks the last thing it was doing before it carries on. You will see that line yourself (`YOUR LAST CYCLE WAS INTERRUPTED`): do what it says.
- The VersaVoice app no longer shows an agent as here or working while this computer is off or has lost its network. After a shutdown it shows resting at once; after a power cut or a lost network, within about 3 minutes. The app update that goes with this release is needed for that.
