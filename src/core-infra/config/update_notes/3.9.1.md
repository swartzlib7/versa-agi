# 3.9.1 — IDE mode: one check command, and a loop the system counts

## Tell the Primary User

- In IDE mode they can now leave a loop running in the chat, for example every 15 minutes for a working day. On each wake you run one command that says whether new messages or due tasks are waiting, and you act only when something is. They choose how the loop ends: a number of hours, a number of quiet checks in a row, or both. When it runs out you close the session without asking, send them one message and turn IDE mode off, unless they asked you to leave the mode on. If the loop stops ticking, or ends without the mode going off, Lifeline tells them. The rules are in `AGENTS.md` of an IDE session; nothing changes outside IDE mode.
- If they have an IDE chat open from before this update, they should reload the IDE window before using it. The tool running the chat keeps the rules file it loaded when it started; `agictl agent ide status coa` now names the installed rules version so an old copy shows.
