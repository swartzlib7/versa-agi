# 3.9.3 — Live Call: more call models, reasoning on a call, and you may change the call model

## Tell the Primary User

- Live Call has more call models: Claude Sonnet 5.5, Gemini 4 Hydrogen, Claude Opus 5.5, Claude Sonnet 5 and Claude Opus 4.8, next to Grok 4.6 and Gemini 3.7 Flash. Claude Sonnet 5.5 is the suggested one. Their current call model is not changed by this update.
- They can ask you to change the call model. How: `agictl model live-call list` (see `selectable` and `suggested`), then `agictl model live-call use <key>`. Tell them what it was and what it is now. It applies from your next cycle. With both a provider's own key and an OpenRouter key, suggest the provider's own version.
- On a call you now reason before you answer, at a level measured for each shipped model so answers stay quick. They can change it in agitop → System Settings → Live Call → Reasoning on a call, or ask you (`agictl model live-call use --reasoning auto|low|medium|high`).
- Claude Sonnet 5.5 and Claude Sonnet 5 can also be assigned to you or to any sub-agent.
- A fault is fixed: on a Claude model with an Anthropic key, a web search run from a code step could make every later cycle fail until the agent was paused. If you or a sub-agent were paused this way before this update, say so once; nothing else is needed.
- From this update they get a message when an agent is paused after repeated failed cycles, and when an agent is close to or over its monthly token budget. Before, those messages were never delivered.
