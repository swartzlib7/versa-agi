# 3.9.2 — Code goes in an attachment, agents can send files, and a message never goes without its attachment

## Tell the Primary User

- From this update, code, commands and logs you send them arrive as an attached document, in typed messages as well as spoken ones. In the VersaVoice AI app they open the attachment to select, copy or save it. The message text itself stays plain conversation.
- If an agent still puts code in the text of a message, they can tell that agent once. Every agent now has the rule and the right attachment command in its instructions.
- You and the sub-agents can now send them files, not only pictures: PDF, Word, Excel, CSV, JSON, INI, TXT, Markdown and ZIP, up to 20 MB each. Audio and video cannot be sent.
- A message now goes out with every attachment it names, or not at all. Before, a file that could not be attached was dropped and the message still said it was attached.
