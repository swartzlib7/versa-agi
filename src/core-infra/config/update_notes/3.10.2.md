# 3.10.2 — New models: Gemini 4 Neon, Gemini 4 Argon, GPT-6.2 Astra

## Maintenance after this update

The stock reasoning level of GPT-6.1 Sol changed from high to medium, on both keys (`gpt-6.1-sol` and `openai/gpt-6.1-sol`). Medium is OpenAI's own default for it. Nothing below is known to be true on this instance. Make the check once and do what its result calls for.

1. **Agents on GPT-6.1 Sol.**
   - Check: `agictl agent list` for an agent whose model is `gpt-6.1-sol` or `openai/gpt-6.1-sol`, and `agictl model params get model:<that key>` for a reasoning level set on this instance.
   - If an agent uses it and the instance has no reasoning level of its own for that key: that agent reasons at medium from its next cycle. Tell the Primary User which agent, and that `agictl model params set model:<that key> --reasoning-effort high` puts it back if they want. Change nothing unless they ask.
   - If the instance has its own level for that key, or no agent uses the model: there is nothing to do.

2. **Versa Desktop is not released.** It is not available to the Primary User or to anyone else yet, and it is not something to suggest. Earlier versions carried desktop commands in your reference pages on every machine.
   - Check: your system memory, awareness, and open or blocked tasks for a suggestion or offer of Versa Desktop, HeteroSphere or "computer use" made to the Primary User or to a connection. For your sub-agents, check their open tasks the same way.
   - If you find one: tell that person once that Versa Desktop is not released yet, close or correct the task, and remove the memory entry that says it is available.
   - If you find none: there is nothing to do.

## Tell the Primary User

- Three models can now be assigned to you or to any sub-agent: Gemini 4 Neon and Gemini 4 Argon (a Google key or OpenRouter) and GPT-6.2 Astra (an OpenAI key or OpenRouter). They are at the end of the model list. No agent's model is changed by this update, and the models suggested at setup are the same as before.
- Gemini 4 Neon and Gemini 4 Argon need a paid Google key: Google does not offer them on its free tier. Through OpenRouter they need no Google key.
- GPT-6.2 Astra is OpenAI's flagship and costs the same as Claude Fable 5.2, the most expensive model offered. It always reasons, at medium unless they choose another level, and it is not used by model routing unless they switch that on for it.
- You and your sub-agents can now reach their cloud files (Google Drive, OneDrive, Dropbox and others) from this machine and reorganise them. The tool for it, rclone, is installed with this update, so nothing has to be installed or approved first. For Google Drive they do a one-time setup in their Google account and a sign-in; you walk them through it and do the rest (skill `cloud_storage.md`).
- A fault is fixed: an agent that had worked on a Gemini 4 model with a Google key failed whenever it woke after its model was changed to Grok with an xAI key, or to any model through OpenRouter. If an agent was paused this way before this update, say so once; nothing else is needed.
- The result of your check on GPT-6.1 Sol, if an agent uses it.
